# SL 智能体实验结论（可复现口径）

> 目标：用监督学习训练一个能在 Simple64 上击败内置 AI（难度 3）的智能体。
> 本文只记录**结论**（配方 / 种子数 / 胜率 / 置信区间 / 判定），不收录失败脚本。
> 判胜口径：`raw_reward = +1`（native 真胜）。评测统一 `OFF_GAME_STEPS=40000`。

## 1. 基线与当前最好

| 配方 | 数据 | 训练 run | 评测局数 | 真胜率 | Wilson 95% | run 级 SD | 可用 run 比例 |
|---|---|---:|---:|---:|---|---:|---:|
| cwB | 30 局 bot 自战 + 30 局规则专家 | 4 | 80 | 31.2% | [22.2, 42.1] | 19.3% | ~43% |
| **h5** | cwB + 5 局人类录像（人类占 12.6%） | 15 | 196 | **46.9%** | [40.1, 53.9] | **13.2%** | **67%** |

- h5 在"可评测 run"上比 cwB 高约 15.7pp（≈2.4σ），但把塌缩 run 计入配方期望后约 36%，
  与历史最好单 run（42.5%）**统计上不可分**。
- 因此 h5 被证明的是**可用率与稳定性**（67% vs 43%，SD 13% vs 19%），不是"胜率更高的配方"。
- 最强单权重：`cwH5_s20261171` 36/60 = 60%；`cwH5h_s20261207` 25/39 = 64%（配对翻转 6:1）。
  单 run 数字受选择偏差影响，引用时必须标注局数。

## 2. 门禁规则（只做准入，不做排序）

| 规则 | 内容 | 证据 |
|---|---|---|
| 单检查点 | 最终 `val_action_acc ≤ 0.55` 才评，`≥ 0.60` 必崩 | 同配方 7/7 命中 |
| 双检查点 | ep4 ≤ 0.55 **或** ep2 ≤ 0.40 可用 | 捞回 2 个可用模型 |
| 早停窗口 | ep2 只在 val ≤ 0.40 时有效；ep1 无效 | h5 塌缩 run 的 ep1 仅 21% |

`val` 只能当门禁，不能用来在 run 之间排序（同批可用 run 里 val 0.313 → 20%、0.306 → 45%）。
跨配方更不成立。**每个配置至少 3 个独立 run**，否则结论不可用。

## 3. 已否证（不要重做）

- 纯专家数据（30/60/90 局，去 no_op）：0 胜。
- DAgger 直接聚合：0/5；热启动只喂新数据：0/4（灾难性遗忘）；热启动+聚合：2 胜 1 平 2 负。
- 权重平均集成（soup2/soup3）：0/5 —— 线性连通性不成立。
- 均衡采样压 `other` 类：0/5 —— `other` 含 Move/Rally/Smart，绝不能压。
- 开局帧加权（`early_w`）、标签平滑、熵正则：加速塌缩或 0–1 胜 / 10 局。
- 推理端动作类型 logits 偏置：留出 20 局 10/20 vs 10/20，零增益。
- 人类录像剂量：0% → 31%、12.6% → 46.9%、17.7% → 40%、24% → 0/5（有上限）。

## 4. 失败形态

- 统一形态是**经济段塌缩**：负局 `food=0 / our_units=1`，开局即断经济。
- 另有"打了但打输"的消耗战：负局步数与 Attack 命令数显著高于胜局。
- 根因指向 BC 复合误差：专家数据里 Attack 占 75.3%、Harvest 仅 1.0%，
  而模型实战 Harvest 49%、Pylon 31%、**Attack 0%** —— 开局无兵 → Attack 非法 → 退化到采矿造塔。

## 5. 工程约束（血泪）

- 单 run 常驻内存约 45 GB，**最多并行 2 个训练**；2 训练 + 评测会 OOM。
- 评测每卡最多 5–6 个并发，否则 `CUDNN_STATUS_NOT_INITIALIZED`。
- fp16 存储把 RSS 从 44.4 GB 降到 23.9 GB（epoch +4%），是提高并行度的唯一可行手段。
- 评测必须 `OFF_GAME_STEPS=40000`；30000 会把优势局打成平。
