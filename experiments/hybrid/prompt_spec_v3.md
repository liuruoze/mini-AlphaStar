> 相对 v2 的根本改动：**从「五选一」改为「五位独立判断」**。
> 理由（用户）：造农民在基地排队、造兵在兵营排队、造建筑由农民执行，三者互不冲突，可以同时进行。

## 1. System（逐字使用）

```
你是星际争霸2神族的战术指挥官。本局固定执行狂热者快攻。以下五件事要分别判断“现在是否该做”，可以同时为真：

1. 补水晶：没有水晶，或（人口余量（上限−已用）≤ 9 且人口上限未满 200）
2. 补农民：农民 ≤ 14 且人口余量 ≥ 1
3. 补兵营：兵营 < 3 且至少有一个水晶（没有能量场就放不下）
4. 量产狂热者：兵 < 24 且矿 ≥ 100 且农民 ≥ 10 且兵营 ≥ 1 且人口余量 ≥ 2
5. 全面进攻：兵 ≥ 8

按 1..5 的顺序输出 5 位 0/1（1 = 现在该做），不要解释。
```

## 2. User 模板（逐字使用）

```
时间 {mm:ss}｜人口 {used}/{cap}（余量 {gap}）

```

**不再出现的字段**：空闲农民（没有任何规则使用它，属纯干扰项，19:33 删除）、敌方信息（未采集）、历史决策（避免路径依赖）。

## 3. 输出格式与依赖

5 位 0/1，可含多个 1。例：`00110` = 补兵营 + 量产狂热者。

唯一的位置依赖：没有水晶 → 第 3 位强制 0（能量场不存在，兵营放不下）。
其余四位相互独立；补水晶与补兵营可同时为 1（两个农民分别去建）。

## 4. 指标（2026-11-20 20:27 定稿：方案 B）

**主指标 = 得分 B**：每题 5 位，按错几位计分。

| 情况 | 得分 |
|---|---:|
| 5 位全对 | **1.0** |
| 只错 1 位（对 4 位） | **0.5** |
| 错 2 位及以上 | **0** |

总分 = 120 题的平均分（0–1）。

**一句话解释**：要么全对，要么差一点给半分，其余不算。

为什么不是"部分对就给 0.5"：那样任何答案在几乎每题上都能碰对至少一位，
"什么都不做"就能拿 **0.517**，分数实际只在 0.5–1.0 之间浮动。方案 B 下它的得分是 0.05。

诊断项（不计入主分）：逐位准确率、逐位明细（看错在哪一条）、格式失败数。

门禁：8 局并发下 p95 延迟 ≤ 30 秒。
判定：得分 B ≥ 0.8 可进在线测试；0.5–0.8 仅离线；< 0.5 淘汰。

| 策略 | 得分 B | 全对率 |

| 全 1（全都做） | 0.042 | 0.8% |
| 逐位多数 / 最常见组合 | 0.154 | 6.7% |

另有约 20 条只该做一件事（答全 0 得 4/5 位，拿 0.5）。这是如实反映，不是漏洞。
