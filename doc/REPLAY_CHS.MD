# 回放

[English](REPLAY.MD) | **中文**

如何下载 SC2 回放？

你可以在[这里](https://github.com/Blizzard/s2client-proto#replay-packs)找到一个很大的回放包
（对应 SC2 3.16.1），包含数十万局回放。

但它并不是版本 >= 4.0 的回放。要拿到更新版本的回放，请试"下载回放"的方式
（可以下载不同版本的回放）。

教程在[这里](https://github.com/Blizzard/s2client-proto/tree/master/samples/replay-api)。
我们也在 mini-AlphaStar 里给出了示例（在 `scripts/download_replay/third`）。

对中国大陆不便使用（境外）Battle.net 的用户，可以用知乎上的这篇
[指南](https://zhuanlan.zhihu.com/p/410523216)：它教你怎么用（国服）Battle.net 客户端，
下载那些放在（美服）Battle.net 上的回放。

如果遇到问题，请开 issue，我们可以讨论。

本文件是 [`REPLAY.MD`](REPLAY.MD) 的中文镜像，内容与英文版一一对应。
