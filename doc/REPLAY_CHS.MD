# 回放

[English](REPLAY.MD) | **中文**

Blizzard 的[回放包](https://github.com/Blizzard/s2client-proto#replay-packs)有数十万局回放，但只
覆盖 SC2 3.16.1，没有 4.0 以上版本。

4.0 以上的回放要用 replay API 下载，教程见
[samples/replay-api](https://github.com/Blizzard/s2client-proto/tree/master/samples/replay-api)，
示例在 `scripts/download_replay/third`。

中国大陆访问境外 Battle.net 不便时，可用知乎这篇[指南](https://zhuanlan.zhihu.com/p/410523216)，
通过国服客户端下载放在美服上的回放。
